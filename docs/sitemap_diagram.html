Recommended rebuild architecture

Front-end

  • Next.js or Astro — static-first, strong SEO, cheap hosting
  • Tailwind CSS for styling
  • Reusable components: Header, Footer, Hero, Gallery, MenuSection, LocationCard, ContactForm
  • A /[location] template so all 5 locations can share one codebase later
  • Self-host the downloaded images & video in /public
  • Host on Vercel or Netlify (auto HTTPS, Git deploys)

Back-end / data

  • Start from the captured JSON files (menu, locations, business info)
  • Graduate to a headless CMS — Sanity / Contentful / Payload — when staff edit menus
  • Content models: MenuItem, Location, Page, SiteSettings
  • Forms → serverless function or Formspree/Basin → email info@lobsterlab.us
  • Ordering & catering stay external (Toast, EZCater)
  • Newsletter via Mailchimp/Klaviyo; Analytics + Search Console; 301 redirects
